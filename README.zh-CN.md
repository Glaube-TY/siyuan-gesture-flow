# 手势流 GestureFlow

GestureFlow 是思源笔记的**手势操作插件**。绘制手势后松开，即可执行绑定的操作。

## 主要功能

- 切换标签页。
- 关闭标签页，或恢复最近关闭的标签页。
- 重新加载当前文档。
- 滚动到文档顶部或底部。
- 后退和前进。
- 将手势绑定到快捷键，并自定义操作名称。
- 自定义录制单段或复合手势。
- 导入、导出和恢复配置。

## 快速开始

1. 安装并启用插件。
2. 打开"手势流设置"。
3. 进入"绑定"。
4. 点击"新增绑定"。
5. 按住鼠标右键绘制轨迹。
6. 选择实现类型（内置功能或快捷键）。
7. 选择内置功能，或填写操作名称并录入快捷键。
8. 保存。
9. 关闭设置页并实际使用手势。

## 绘制手势

- 当前首发版本支持**桌面端鼠标右键输入手势**。
- 按住鼠标右键，移动鼠标，松开完成。
- 支持方向：**上（U）、下（D）、左（L）、右（R）**，以及 `右 → 下` 这样的复合轨迹。
- 开启 **8 方向**后，还支持斜向（如 `↖ ↗ ↘ ↙`）。
- 按住右键但**不移动**时，仍显示思源普通右键菜单。
- 按住临时禁用键时，可以直接使用普通右键。

## 实现类型

| 类型 | 说明 |
| --- | --- |
| 内置功能 | 从功能列表中选择（见下表）。 |
| 快捷键 | 填写**操作名称**（例如：打开全局搜索），点击录入框，按下组合键；保存后关闭设置窗口，用真实手势最终验证。 |
| JavaScript | 显示为**开发中**，当前不可使用。 |

## 内置功能列表

| 名称 | 作用 |
| --- | --- |
| 上一个标签页 | 切换到当前窗口的上一个标签页。 |
| 下一个标签页 | 切换到当前窗口的下一个标签页。 |
| 关闭当前标签页 | 关闭当前活动标签页。 |
| 恢复最近关闭的标签页 | 恢复最近关闭的标签页（使用思源自身的恢复流程）。 |
| 重新加载当前文档 | 重新加载当前活动文档。 |
| 滚动到顶部 | 将当前文档滚动到顶部。 |
| 滚动到底部 | 将当前文档滚动到底部。 |
| 后退 | 在导航历史中后退一步。 |
| 前进 | 在导航历史中前进一步。 |

> 新增动作（关闭、恢复、重新加载、后退、前进）**没有默认手势**，请在绑定页为它们录制自己的轨迹。

## 快捷键兼容性

- 快捷键通过**合成键盘事件**发送，GestureFlow 不会伪造可信键盘事件。
- 思源内置快捷键通常可以响应。
- 是否生效可能取决于当前焦点区域。
- 主动检查 `isTrusted` 的少数插件可能无法响应。
- 应关闭设置窗口后，在快捷键本来有效的场景中用真实手势验证。

## 设置说明

| 标签页 | 用途 |
| --- | --- |
| 常规 | 启用/停用插件、临时禁用键、激活距离和超时。 |
| 识别 | 方向模式（4/8 方向）、采样和简化灵敏度。 |
| 显示 | 轨迹和提示开关、线宽。 |
| 绑定 | 录制手势并管理绑定（新增 / 编辑 / 删除 / 启停）。 |
| 数据 | 导出、导入和恢复默认配置。 |

## 常见问题

**普通右键菜单还能用吗？**
能。右键不移动时仍会显示思源右键菜单；需要时按住临时禁用键即可使用普通右键。

**为什么某个快捷键没有反应？**
快捷键会派发到当前焦点。有些快捷键与上下文相关（例如只在编辑器内生效），主动拒绝合成事件的插件也不会响应。请关闭设置窗口，在快捷键本来有效的场景中用真实手势验证。

**为什么手势没有被识别？**
轨迹可能太短、太长或画得太慢。请检查激活距离和超时设置，并确认方向序列与已保存的绑定一致（未开启 8 方向时斜向不会识别）。

**怎样临时停用手势？**
在"常规"中关闭插件，或按住已配置的临时禁用键。

**怎样备份配置？**
在"数据"页点击"导出配置"，会下载一个 JSON 文件；"导入配置"可恢复，"恢复默认"回到默认值。

**为什么 JavaScript 不能选择？**
JavaScript 功能正在开发中，为安全起见当前不可用。
