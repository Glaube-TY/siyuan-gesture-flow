# 手势流 GestureFlow

GestureFlow 是思源笔记的**手势操作插件**。使用鼠标右键或 Windows 笔记本触控板绘制手势，松开后即可执行绑定的操作。

## 主要功能

- 切换、关闭或恢复标签页。
- 新建文档、打开今日日记或最近文档等。
- 全局搜索，或搜索选中文本。
- 显示或隐藏侧栏面板（文件树、大纲、反向链接等）与关系图。
- 分屏与取消分屏。
- 打开设置、立即同步、切换只读模式或锁定屏幕。
- 滚动到文档顶部或底部。
- 后退和前进。
- 将手势绑定到快捷键，并自定义操作名称。
- 自定义录制单段或复合手势。
- 使用 Windows 触控板录制多指点击、滑动、独立轨迹、固定指绘制、捏合和旋转。
- 导入、导出和恢复配置。

## 快速开始

1. 安装并启用插件。
2. 打开"手势流设置"。
3. 如需触控板输入，在"常规"中开启"启用触控板"。
4. 进入"绑定"，点击"新增绑定"。
5. 选择输入方式：鼠标或触控板。
6. 鼠标：按住右键绘制；触控板：点击方形录制面板，然后在真实触控板上完成动作并松开全部手指。
7. 选择实现类型（内置功能或快捷键）。
8. 选择内置功能，或填写操作名称并录入快捷键。
9. 保存，关闭设置页后实际使用手势。

## 鼠标右键手势

- 按住鼠标右键，移动鼠标，松开完成。
- 支持方向：**上（U）、下（D）、左（L）、右（R）**，以及 `右 → 下` 这样的复合轨迹。
- 开启 **8 方向**后，还支持斜向（如 `↖ ↗ ↘ ↙`）。
- 按住右键但**不移动**时，仍显示思源普通右键菜单。
- 按住临时禁用键时，可以直接使用普通右键。

## Windows 触控板手势

### 录制和使用

- 在"绑定"中新增或编辑绑定，把输入方式切换为"触控板"。
- 直接点击方形录制面板开始录制，不需要单独点击外部按钮。
- 不需要预先选择手指数。插件会从设备帧中自动记录实际手指数和每根手指的轨迹。
- 手指接触后开始解析；**全部手指离开触控板**时完成本次手势，并冻结结果供保存。
- 支持轻点、长按、同向滑动、共享复合轨迹、每指独立轨迹、固定手指 + 另一手指绘制、捏合和旋转。
- 录制和实际使用时会按手指数显示多条轨迹；识别完成后还会显示将要执行的具体功能。

### 与 Windows 系统手势的关系

为了避免同一个动作同时触发 Windows 和 GestureFlow，插件只屏蔽常见且不可避免的基础交互：

- **一指**：指针移动和点击始终交给系统，不能作为插件手势。
- **二指**：点击/按压右键、同方向滚动或平移、捏合缩放会被屏蔽。
- **三指**：三指轻点会被屏蔽。
- **允许**：二指各自绘制不同轨迹、带固定指的绘制、旋转，以及三指及以上除三指轻点外的滑动、复合轨迹、独立轨迹、长按、捏合和旋转。

Windows 设置中"可以配置"三指或四指动作，不代表该动作当前已经启用。GestureFlow 不会修改系统触控板设置，也不会仅因为某个动作可以配置就提前屏蔽它。可参考 [Microsoft 官方触控手势说明](https://support.microsoft.com/windows/hardware/input-devices/touch-gestures-for-windows)。

### 兼容性和安装环境

- 完整的逐触点、多指轨迹功能目前面向 **Windows x64 桌面版思源**，需要系统能够识别兼容的触控板及驱动。
- 发布包已内置预编译的 `native/gesture_flow_touchpad.node`。普通用户只需安装并启用插件，**不需要安装 Node.js、Python、pnpm、Visual Studio 或 Windows SDK**。
- 原生模块无法加载时会尝试使用 Electron 事件观察模式；该模式只能提供部分系统级手势，不能完整录制每根手指的独立轨迹。
- Windows ARM64、macOS、Linux、移动端和浏览器端目前不提供完整的高级触控板功能；鼠标手势不受影响。

## 快捷键兼容性

- 快捷键通过**合成键盘事件**发送，GestureFlow 不会伪造可信键盘事件。
- 思源内置快捷键通常可以响应。
- 是否生效可能取决于当前焦点区域。
- 主动检查 `isTrusted` 的少数插件可能无法响应。
- 应关闭设置窗口后，在快捷键本来有效的场景中用真实手势验证。

## 常见问题

**普通右键菜单还能用吗？**
能。右键不移动时仍会显示思源右键菜单；需要时按住临时禁用键即可使用普通右键。

**为什么某个快捷键没有反应？**
快捷键会派发到当前焦点。有些快捷键与上下文相关（例如只在编辑器内生效），主动拒绝合成事件的插件也不会响应。请关闭设置窗口，在快捷键本来有效的场景中用真实手势验证。

**为什么手势没有被识别？**
轨迹可能太短、太长或画得太慢。请检查激活距离和超时设置，并确认输入方式、手指数和方向序列与已保存的绑定一致（未开启 8 方向时斜向不会识别）。触控板录制需要原生逐触点数据；若界面提示观察模式，请先确认使用的是 Windows x64 桌面版思源。

**怎样录制触控板手势？**
新增绑定后选择"触控板"，点击方形录制面板，再直接在笔记本触控板上完成动作。手指数和每指轨迹会自动识别，松开全部手指后自动结束。

**为什么某些触控板动作不能保存？**
它们与 Windows 的一指指针、二指右键/滚动/缩放或三指轻点冲突。请改用不同手指轨迹、复合转折、固定指绘制，或其他三指及以上动作。

**其他用户需要安装 Node.js 或编译环境吗？**
不需要。Windows x64 发布包已经包含编译好的原生模块；Node.js、Python、Visual Studio 等只用于开发和发布构建。

**怎样临时停用手势？**
在"常规"中关闭插件，或按住已配置的临时禁用键。

**怎样备份配置？**
在"数据"页点击"导出配置"，会下载一个 JSON 文件；"导入配置"可恢复，"恢复默认"回到默认值。

**为什么 JavaScript 不能选择？**
JavaScript 功能正在开发中，为安全起见当前不可用。
